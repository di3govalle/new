# watsonx Orchestrate — Intern Onboarding

A start-to-finish checklist for getting a new intern set up: laptop, IBM
accounts, Slack, access requests, and the starter project. Work top to bottom.

> **A note on credentials before you start:** never print, paste, screenshot, or
> message anyone's password. Hand off a temporary password securely (in person
> or via an approved secrets channel), and have the intern change it and set a
> **passkey** on first login. Usernames are fine to share; passwords are not.

---

- [ ] **Do show / no-show confirmation immediately** on day one.

## Part A — Set up the laptop

1. **Have your IBM w3 username + temporary password ready** (from your onboarding
   manager).
2. **Get on the network.**
   - Once logged into the machine you should be able to join the **IBM network**.
   - If you can't, install **IBM Wireless Setup** from the **mac@ibm** store.
   - Make sure you're signed in to the **mac@ibm** store with your **IBM w3
     id/password**.
   - If you don't have the mac@ibm store, go to
     <https://setupmydevice.ibm.com/>.
   - **Guest Wi-Fi** is available as a *temporary* bridge while you get the IBM
     network working — create/share it here:
     <https://cio-neteng-edge-gwm-app-prod.06f18550.public.multi-containers.ibm.com/>.
     Move onto the proper IBM network as soon as you can; guest Wi-Fi is
     isolated and not meant for daily work.
3. **Install core apps first** from the mac@ibm store: **Outlook** and **Slack**.
   - **Set up Outlook first** — you'll need email-based 2FA to finish Slack
     setup.
4. **Run OS updates** once the machine is otherwise set up and on the network,
   then reboot.

> ⚠️ **Personal Apple ID — check policy first.** Some onboarding notes suggest
> signing into a personal Apple ID "to store passwords and passkeys." On an
> **IBM-managed Mac this may conflict with device/security policy** (it can sync
> corporate data into personal iCloud and complicate device return). **Verify
> against current IBM device policy before doing this.** For passwords/passkeys,
> prefer your **w3id passkey** and any IBM-sanctioned password manager.
